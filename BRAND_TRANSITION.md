# Nerava brand transition

The public product name is now **Nerava**. The following technical identifiers deliberately remain on the existing KaribuStay domain until the Nerava domain and email service have been purchased and configured:

- `https://karibustay.co.tz` and its password-reset URL
- `info@karibustay.com` and `info@karibustay.co.tz`
- Supabase project URL and existing database

Before public launch, buy a suitable Nerava domain, create a support email address on that domain, connect it in Vercel and Supabase, then update the remaining URLs and support email addresses together. Do not change the existing Supabase project URL.

The Android and iOS identifiers are now `com.nerava.customer` and `com.nerava.host`. These are correct for the first Store release. After an app has been published, do not change its identifier; future updates must keep it.

Run a trademark search in BRELA and WIPO before completing public registration of the Nerava name and logo.
